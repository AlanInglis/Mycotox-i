# Mycotox-i

This repository contains code used in the **Mycotox-I** project, which focuses on using deep and transfer learning methods to predict mycotoxin
presence and level in Irish oat crops. Specifically the code relates to the results in the Predicting Mycotoxin Contamination in Irish Oats Using Deep and Transfer Learning paper. 

The scripts contain the neural network and transfer learning model code that are used in the paper.
